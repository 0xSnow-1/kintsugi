# Kintsugi

A fault-tolerant stateful agent orchestrator built on LangGraph and PostgreSQL.

At-most-once external side-effects across hard crashes. Confidence-scored model routing from Groq System-1 to Claude Sonnet System-2. A deterministic SIGKILL chaos test as the source of truth.

Read `Constitution/mission.md` for the promises, `Constitution/techstack.md` for the stack decisions, and `Constitution/roadmap.md` for the phase plan.

Implementation is scaffolded per `specs/26-10-13-phase-0-scaffold/`.
